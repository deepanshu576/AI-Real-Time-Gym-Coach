# AI-Real-Time-Gym-Coach
Real-time AI Gym Coach using MediaPipe, Streamlit, Groq LLM and Text-to-Speech.

A real-time AI fitness coach built using:

- Python
- Streamlit
- MediaPipe
- OpenCV
- Groq LLM
- Text-to-Speech
- streamlit-webrtc

## Features

- Real-time pose detection
- Rep counting
- Set counting
- AI voice coaching
- Workout history
- User login
